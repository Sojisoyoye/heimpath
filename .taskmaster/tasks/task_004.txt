# Task ID: 4
# Title: Create Document Translation Engine
# Status: done
# Dependencies: 1
# Priority: high
# Description: Build an AI-powered document translation service that converts German real estate documents (contracts, leases, property listings) into English with automatic detection of key clauses and risk warnings. Supports PDF upload (max 10 pages free tier, 20 pages premium), automatic document type detection, DeepL API integration for translation, key clause detection and highlighting, risk detection and warnings.
# Details:
Supported document types:
- Kaufvertrag (Purchase Contract)
- Mietvertrag (Rental Agreement)
- Exposé (Property Listing)
- Nebenkostenabrechnung (Utility Statement)
- Grundbuchauszug (Land Registry Extract)
- Teilungserklärung (Condo Declaration)
- Hausgeldabrechnung (Condo Fee Statement)

Key clause detection:
- Purchase price and payment terms
- Dates and deadlines
- Warranty exclusions
- Special conditions
- Financial terms (rent, deposits, fees)

Risk warnings for:
- High-risk clauses (e.g., 'Gewährleistung ausgeschlossen')
- Unusual terms requiring attention
- Missing required information

Technical requirements:
- DeepL API integration (official Python SDK)
- PDF text extraction (pdfplumber library)
- Async processing (Celery background tasks)
- Document storage (AWS S3, encrypted at rest)
- Progress tracking and status updates
- Usage limit enforcement per subscription tier
- Keyword matching for clause detection (regex patterns)

Endpoints:
- POST /api/v1/documents/upload
- GET /api/v1/documents/{document_id}
- GET /api/v1/documents/{document_id}/translation
- GET /api/v1/documents/{document_id}/status
- GET /api/v1/documents/ (list user's documents)

# Test Strategy:
Unit tests for clause detection, integration tests for DeepL API, E2E tests for document upload and translation flow
