# Task ID: 7
# Title: Create Financing Eligibility Wizard
# Status: done
# Dependencies: 1
# Priority: high
# Description: Build an interactive multi-step questionnaire that assesses user's likelihood of obtaining mortgage financing in Germany and provides personalized recommendations and document checklist. Includes 7-question wizard, eligibility score calculation (0-100), personalized results with strengths and areas to improve, and required documents checklist.
# Details:
7-question wizard collecting:
- Employment status (permanent/self-employed/other)
- Years at current employer
- Monthly net income
- Existing monthly debt obligations
- Down payment available
- Credit history (SCHUFA: good/fair/poor/unknown)
- Citizenship/residency status

Eligibility score calculation (0-100):
- Weighted scoring algorithm
- Strong factors: Permanent employment 2+ years, good income-to-debt ratio, 20%+ down payment
- Moderate factors: EU citizenship, good SCHUFA, stable income
- Weak factors: Self-employed, non-EU, limited credit history, low down payment

Likelihood assessment:
- 80-100: High likelihood (green)
- 60-79: Good likelihood (light green)
- 40-59: Moderate likelihood (yellow)
- 20-39: Low likelihood (orange)
- 0-19: Very low likelihood (red)

Personalized results:
- Overall likelihood verdict
- Strengths (green checkmarks)
- Areas to strengthen (orange warnings with actionable advice)
- Maximum loan amount estimate
- Recommended down payment percentage
- Expected interest rate range
- Likely loan-to-value ratio

Required documents checklist (personalized):
- Essential documents (all applicants)
- Additional documents (based on user's situation)
- Format requirements
- Tips for obtaining each document
- Downloadable PDF checklist

Endpoints:
- POST /api/v1/financing/eligibility
- GET /api/v1/financing/eligibility/{assessment_id}
- GET /api/v1/financing/documents-checklist/{assessment_id}

# Test Strategy:
Unit tests for scoring algorithm, integration tests for wizard flow, validation with sample user profiles

## 3. Implement eligibility scoring algorithm [done]
### Dependencies: None
### Description: Create backend/app/services/financing_service.py with module-level functions. Core function calculate_eligibility(inputs) returns EligibilityResult dataclass. Weighted scoring (0-100): employment_status (20pts — permanent 2+yr=20, permanent <2yr=14, self-employed 3+yr=10, self-employed <3yr=5, other=2), income_to_debt_ratio (20pts — ratio >5:1=20, 4:1=16, 3:1=12, 2:1=6, <2:1=2), down_payment_pct (20pts — 30%+=20, 20-29%=16, 15-19%=10, 10-14%=6, <10%=2), schufa_rating (15pts — good=15, fair=10, poor=3, unknown=5), residency_status (15pts — german=15, eu=13, permanent_resident=10, non_eu=5), employment_years bonus (10pts — 5+yr=10, 3-4yr=7, 1-2yr=4, <1yr=1). Calculate max_loan_estimate = monthly_net_income * 110 * (1 - debt_ratio). Generate likelihood_label based on score ranges.
