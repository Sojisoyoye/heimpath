# Task ID: 1
# Title: Implement User Authentication and Account Management System
# Status: done
# Dependencies: None
# Priority: high
# Description: Build a secure user registration, authentication, and account management system enabling users to create accounts, log in securely, manage their profiles, and control their subscription status. Includes email/password registration with email verification, JWT token-based authentication, password reset via email, user profile management, subscription management via Stripe integration, and GDPR compliance features (data export, account deletion).
# Details:
Technical requirements:
- JWT token generation and validation with 30-day expiration for 'remember me' and 24-hour default
- Bcrypt password hashing (cost factor 12)
- Email verification service integration
- Rate limiting (5 failed login attempts = 15-min lockout)
- HTTPS/TLS for all authentication endpoints
- Stripe integration for payment/subscription management
- OWASP Top 10 compliance
- Audit logging of authentication events

Database models:
- User model with email, password_hash, full_name, citizenship, email_verified, created_at, updated_at
- Session/token management
- Subscription status tracking

Endpoints needed:
- POST /api/v1/auth/register
- POST /api/v1/auth/login
- POST /api/v1/auth/logout
- POST /api/v1/auth/verify-email
- POST /api/v1/auth/forgot-password
- POST /api/v1/auth/reset-password
- GET /api/v1/users/me
- PUT /api/v1/users/me
- DELETE /api/v1/users/me (GDPR)
- GET /api/v1/users/me/export (GDPR)

# Test Strategy:
Unit tests for auth service, integration tests for auth endpoints, security testing for OWASP compliance
