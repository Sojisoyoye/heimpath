# Claude Code Instructions for HeimPath

## Git Commits
- Do NOT include Claude session URLs in commit messages
- Do NOT add `Co-Authored-By: Claude` or any Claude/Anthropic attribution to commits
- Do NOT add `Claude-Session:` lines to commits
- Commit messages should only contain the author's own attribution

## Pull Requests
- Do NOT include "Generated with Claude Code" in PR descriptions
- Do NOT include Claude session links in PR bodies
- PR descriptions should be written as if authored by the developer

## General
- No Claude branding or attribution anywhere in the repository
