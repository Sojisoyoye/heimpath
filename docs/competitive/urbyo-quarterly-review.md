# Urbyo Quarterly Competitive Review

Urbyo is HeimPath's closest direct competitor — the only platform that could replicate the "guided DIY" positioning by shipping document translation. This review runs every quarter to track whether the competitive gap is widening or narrowing.

**Cadence:** End of each calendar quarter (March, June, September, December)

---

## Review Checklist

Run these five checks each quarter and capture findings in the log below.

1. **Product changelog & blog** — check Urbyo's website, app release notes, and blog for new features
2. **Job postings** — scan LinkedIn/their careers page for engineering roles (NLP, document processing, AI signals what they're building next)
3. **App Store / Play Store reviews** — filter reviews mentioning document handling, translation, or legal guidance
4. **Expat forum mentions** — search Reddit r/germany, r/eupersonalfinance, Toytown Germany, InterNations for user comparisons
5. **Side-by-side feature table** — update the comparison table at the end of this file

**Additional signals to watch:**
- Fundraising announcements (new capital = new feature velocity)
- Press mentions of Urbyo + "document" / "translation" / "AI"
- LinkedIn posts from Urbyo engineers about document AI work

**Output:** A one-paragraph summary answering: *"Has the gap widened or narrowed? Does document translation investment need to accelerate?"*
